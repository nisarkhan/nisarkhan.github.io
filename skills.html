Adding a Skill to Claude Code

Two ways to add a skill to a project. No restart needed either way — Claude Code picks up file changes live.

1In VS Code / the project folder

Create SKILL.md inside a new folder at this path. For a skill available in every project, use ~/.claude/skills/<skill-name>/ instead.

.claude/skills/<skill-name>/SKILL.md
---
description: What this skill does and when Claude should use it
---

# Instructions Claude follows when this skill is invoked
...

2From the terminal

There's no dedicated command to create a skill — skills are files, so mkdir + writing SKILL.md is the terminal method:

# create the folder
mkdir -p .claude/skills/<skill-name>

# then write SKILL.md into it, e.g.
nano .claude/skills/<skill-name>/SKILL.md
⚠

A skill bundled inside a plugin can be added with /plugin install <name>@<marketplace> — but that installs someone else's plugin, it doesn't create a new skill of your own.

3Installing an existing skill — sf-skills

Same command either way — run it in VS Code's integrated terminal (Terminal → New Terminal) or any regular terminal, from your project root.

one specific skill
npx skills add forcedotcom/sf-skills \
  --skill platform-custom-lightning-type-generate \
  --agent claude-code
every skill in the repo
npx skills add forcedotcom/sf-skills \
  --agent claude-code

4Installing an existing skill — agentforce-adlc

SalesforceAIResearch/agentforce-adlc isn't an npx skills add package — it ships as a Claude Code plugin instead, so it installs differently:

recommended — via plugin marketplace
claude plugin marketplace add SalesforceAIResearch/agentforce-adlc
claude plugin install agentforce-adlc@agentforce-adlc
alternative — clone and point Claude Code at it
# 1. clone it anywhere — no need to cd into it after
git clone https://github.com/SalesforceAIResearch/agentforce-adlc.git

# 2. launch Claude Code pointed at that folder (path is relative to
#    wherever you run this from — one-time flag, per session)
claude --plugin-dir ./agentforce-adlc

# 3. confirm it loaded — /help → "Custom commands" tab lists its
#    skills, or just invoke one directly, e.g.:
/agentforce-adlc:agentforce-generate

You'll need --plugin-dir every time you start a new session unless you scaffold it permanently instead: claude plugin init installs a plugin under ~/.claude/skills/ so it's available automatically on future launches.

5Already inside VS Code?

The Claude Code VS Code extension has a GUI for this, but it's a wrapper over the same CLI commands above — nothing is VS Code-exclusive.

in the Claude Code chat panel
/plugins

Opens Manage plugins — click Install, pick a scope (you / this project / local), done. Anything installed this way also shows up if you switch to the terminal, and vice versa.

Prefer the terminal instead? VS Code's built-in one works identically — Terminal → New Terminal (or Ctrl+` / Cmd+`), then run any command from steps 3–4 above exactly as shown.
